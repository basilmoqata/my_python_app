# Sanad Voice Assistant (مشروع سند - المساعد الصوتي الذكي)

A web-based AI voice assistant prototype tailored for elderly and illiterate citizens in Jordan, supporting local Jordanian dialects for simplified government service access.

## 🚀 Features
* **Web-Based Interface:** Built using Flask framework for lightweight and scalable deployment.
* **Dialect Understanding:** Designed to interpret local Jordanian phrasing (e.g., requesting civil status services like ID renewals).
* **Accessibility Focused:** Large UI components and simple interactions tailored for users with low digital literacy.

## 🛠️ Tech Stack
* **Backend:** Python, Flask
* **Frontend:** HTML5, CSS3, JavaScript (Fetch API)
* **Version Control:** Git & GitHub
