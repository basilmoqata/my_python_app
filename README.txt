1. Project Overview:
This tool is an automated security scanner built using Python. It scans target URLs/servers for common security header vulnerabilities and generates structured security reports automatically.

2. Technologies Used:
- Python 3.x
- Requests Library (for HTTP header analysis and connection handling)
- Datetime (for timestamping reports)
- File I/O (for automated text report generation)

3. How to Run:
- Make sure Python is installed on your system.
- Install required dependencies by running: pip install requests
- Run the script: python scanner.py
- Enter the target URL or domain when prompted to generate the security report.
